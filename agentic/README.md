## AI YouTube Video Automation Agent

This project turns a single narration script into a production-ready YouTube upload blueprint. It simulates the full automation stack that faceless channels rely on: neural voice synthesis, scene-aware visuals, music pairing, SEO metadata, and upload orchestration.

### Features

- **Script ingestion** with production personas, target audience, and scheduling controls.
- **AI voiceover plan** showing synthesized transcript segments, voice style, and export link.
- **Visual storyboard** covering b-roll, motion graphics, subtitle overlays, and timing cues.
- **Music bed designer** that balances BPM, mood, and dynamic mixing notes.
- **SEO autopilot** producing titles, descriptions, tags, thumbnails, and chapter markers.
- **Upload automation brief** with playlists, cards, end screens, and scheduling metadata.

### Local Development

```bash
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to pilot the agent.

### Production Build

```bash
npm run build
npm run start
```

This project is optimized for Vercel deployment and uses the Next.js App Router with Tailwind styling.
